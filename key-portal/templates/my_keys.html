💡 如何查看我的 API Key？

在终端执行以下命令：

cat ~/.claude/settings.json | grep apiKeyHelper

输出中 "echo" 后面的就是你的 API Key

🗑 安全移除代理配置

如需恢复为官方 Claude Code（移除代理配置但保留 MCP/permissions 等设置）：

仅移除 apiKeyHelper 和 ANTHROPIC_BASE_URL，不影响其他配置
